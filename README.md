## 判定口径与边界（请连同清单一起读）

- 判定完全基于**域名与名称形态**，与公开的官方域名表比对，规则机械、可复核、可重跑；**没有逐一打开站点核验内容**。
- 因此全部结论均为「**疑似**」表述——这是**风险提示**，不是内容鉴定，也不构成对任何主体的定性。
- 正因为未逐站核验，可能存在「同一机构使用第二域名」等误判情形。
